## 规则（与用户确认一致）
- **照原图改，错的全改；绝不删原图里真实存在的原子/键。**
- 波浪线（squiggle）：被读成假烷基（甲基/乙基/异丙基/叔丁基）→ 删该假烷基 + `add_waves` 补游离 `.C~C`（bond order 7）；被读成单键（波浪键画在某根实键上）→ 该键 order 改 7。
- 杂原子文字（NH/OH…）→ 真实元素；含碳文字（CF3/TMS-Si(Me)3/Boc/OMe/R…）→ 保留超原子 `[内容]`。
- 游离 `.C~C` 为 disconnected 片段，即使原图波浪线由一根短键连到环/链上（沿用 approved 孪生 169–191 / 505 等的既有约定）。

## 画像规律
本段多为「Markush 骨架 + 端基/环上波浪线」：苯环/联苯/三联苯/三亚苯/噻吩/吡啶… 一端或两端画波浪线，MolScribe 把波浪线读成假甲基/异丙基等。
- 单端波浪线 → 删 1 个假甲基（delete [0] 或 [2,3,4] 等）＋补 1 个 `.C~C`。
- 双端波浪线 → 删 2 个假甲基（delete [0,5] / [0,9] / [0,5,6,7]）＋补 2 个 `.C~C`。
- 双端假异丙基 → delete [0,5,6,7]（假异丙基=中心+2甲基）＋补 2 个 `.C~C`（如 833/845/857/863/869/875/881/887/893/899/905/911/917）。
- 保留真实取代基：CF3（906–909）、TMS `Si(Me)3`（912–915）、三联苯的两个苯基（918–921）。

# 2026-10-10 二次更正：端部波浪线「连回母核」（833–922）

**用户再次指出**：833–922 里 molscribe 结构与原图不符，**很多都缺一根单键**（也有其他情况）。

**根因（这次是约定问题，不是误删）**：上一轮把所有端部波浪线一律做成**游离 `.C~C`**（片段脱离母核）。原图里从环/链到波浪线其实画了 **一根键**；游离片段在 RDKit 里渲染成**悬空虚线**，母核那一侧就是空的 → 视觉上"少一根单键"。（已 approved 的 505/169 也是游离，属同一遗留问题。）

**排查手段**：
- `ov2.py` 全对比度叠加（原图 + raw 图键彩线 + 原子点）逐张看两端是**锯齿(波浪)** 还是**直键(真取代基)**。833–922 逐张确认：除 858–861 右端是真甲基（上一轮已留）外，其余端部全是锯齿。
- `missbond.py` 几何检测（两原子距离≈键长、中间有墨迹、raw 无键）：除 846/849/914 三个乱码样本外**未检出真实漏键**。
- 确认根因是「游离片段」渲染问题，而非键缺失。

**修法**（新增 `wave_connect()`，`WAVE_CONNECT = range(833,923)`）：端部波浪端**保留 1 个碳**，把「母核→该碳」的键 **order 改 7**（波浪键、连回分子），多余假碳删除。渲染成**连在母核上的波浪短枝**，与原图一致。真取代基（F/OMe/CF3/TMS/tBu/真甲基/苯基）不在 delete 集内，原样保留。
