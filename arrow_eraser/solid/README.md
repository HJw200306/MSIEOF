# 实线及弯曲箭头资产

## 最终三分类数据集

`dataset/SolidArrow-Seg` 已由全部人工审核完成的2011份标注构建。完全相同的图片按组整合为1857张唯一图片；同图的多份人工掩膜按像素多数意见合并，偶数平局保留前景。类别为0背景、1箭头、2化学键、255忽略。工作区继续保留实线/虚线类型；三分类导出将二者合并为箭头，箭头与化学键重叠处按化学键优先。

最终划分为训练1467张、验证193张、测试197张。跨集合的完全相同图片组按测试、验证、训练的优先级整体放置，防止验证或测试图片进入训练集。三个集合之间的精确图像哈希重叠均为0。构建信息见 `dataset/SolidArrow-Seg/dataset_info.json`，逐像素映射与跨划分重复检查见 `dataset/SolidArrow-Seg/quality_report.json`。初次未去重的派生输出保存在 `dataset/SolidArrow-Seg_pre_dedup_20261027`，仅供追溯，不应用于训练或评价。

## 已归档内容

- `training_legacy_vgg_unet/`：来自外置盘的 VGG16 U-Net 训练工程，已把数据路径改为相对路径。
- `dataset/VOCdevkit/VOC2007/`：2011 对图像/掩膜，划分为 1608 train、201 val、199 test；标签像素值为 0 和 1。
- `runtime/`：当前项目加载三分类实线模型所需的 `nets`、`split_tools` 和验证脚本副本。
- 当前三分类权重位于 `../models/solid_arrow_model.pth`。
- `annotation/`：在历史二分类箭头掩膜上补充化学键类别的预标注、人工复核、审计和数据集构建工具。

## 重要数据边界

外置盘训练脚本设置 `num_classes = 2`，与该 VOC 数据集的二分类掩膜一致。因此这套历史工程可用于复现实线箭头二分类训练，但不能直接证明或复现论文所述的“背景/箭头/化学键”三分类训练。

外置盘中的 `VOC2007r` 标注红色 R 基团，不是箭头数据，已明确排除。

历史权重的原始训练过程仍然不能由旧二分类工程直接证明；目前的 `SolidArrow-Seg` 是在保留历史箭头标注的基础上，经模型预标注和完整人工复核后重新建立的三分类数据集。

## 新三分类标注工作区

已经使用当前三分类实线模型为2011张历史图像生成化学键预标注，同时保留原人工箭头掩膜：

- 工作区：`annotation/annotation_v1/`
- 工作区类别：`0=background`、`1=solid_arrow`、`2=bond`、`3=solid_arrow+bond`、`4=dashed_arrow`、`6=dashed_arrow+bond`、`255=ignore`
- 初始化学键阈值：0.50
- 审核状态：2011张全部审核完成
- 原划分遗漏的风格迁移增强样本：703、709、716，已明确补入训练集；它们没有化学键，因此类别2为空是合法标签

双击 `../启动实线箭头化学键标注器.bat` 可以继续查看或修改标注。完整说明见 `annotation/README.md`。

## 运行

在 `arrow_eraser` 目录执行：

```powershell
python solid/training_legacy_vgg_unet/train.py
```

训练日志默认写入当前工作目录的 `logs/`。如需与现有三分类权重比较，应分别报告箭头像素指标与化学键保护指标，不要只比较总体准确率。
