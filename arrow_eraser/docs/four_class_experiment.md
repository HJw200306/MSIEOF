# 统一三分类与四分类受控对照方案

## 1. 实验目标

核心假设只有一个：**把实线/弯曲箭头与虚线箭头设为两个监督类别，是否能减少统一模型中的形态竞争，从而提高合并后的箭头分割质量，尤其是虚线箭头召回与残留率。**

四分类不是预设的最终方案，而是对这一机制假设的直接检验。实验只比较类别定义，不同时更换骨干网络、数据、增强或推理后处理。

## 2. 模型组与准确命名

| 编号 | 名称 | 模型输出 | 是否训练 | 实验职责 |
|---|---|---|---|---|
| A | 双模型并行推理＋输出融合 | 实线三分类模型与虚线三分类模型的预测融合 | 否 | 当前系统基线 |
| B | 统一三分类 | 背景、全部箭头、化学键 | 重新训练 | 类别合并对照 |
| C | 统一四分类 | 背景、实线/弯曲箭头、虚线箭头、化学键 | 重新训练 | 检验分离箭头类型的价值 |

A 不是“先擦实线，再对处理图擦虚线”的串联流程。两个模型均读取同一原图，随后执行箭头并集、化学键并集且化学键优先的固定融合规则。报告和文件名统一使用 `dual_parallel_fusion`。

## 3. 先建立四分类母标签

### 3.1 母标签定义

| 像素值 | 类别 |
|---:|---|
| 0 | background |
| 1 | solid_or_curved_arrow |
| 2 | dashed_arrow |
| 3 | bond |
| 255 | ignore |

箭头与化学键重叠时延续当前业务规则：化学键优先，输出类别3。无法可靠判断箭头类型的像素设为255，不根据文件名前缀猜测。

### 3.2 可用原始标注

不能从现有统一三分类掩膜或 `solid_`、`dashed_` 前缀恢复类型，但可以从仍保留类型信息的原始工作区重建：

- `solid/annotation/annotation_v1` 的工作区编码为：1=实线箭头，2=化学键，3=实线+键，4=虚线箭头，6=虚线+键，255=忽略。2011条标注全部已审核；审计中有58条标注含虚线，共38371个虚线箭头像素。
- `dashed/annotation/annotation_v2` 有99张已审核真实图；其类别1按该工作区任务定义为虚线箭头，类别2为化学键。
- 虚线合成数据的箭头几何由生成程序同步产生，可直接映射为虚线类别。

### 3.3 导出映射

实线工作区：

| 工作区值 | 四分类值 |
|---:|---:|
| 0 | 0 |
| 1 | 1 |
| 4 | 2 |
| 2、3、6 | 3 |
| 255 | 255 |

虚线工作区及其合成数据：

| 原值 | 四分类值 |
|---:|---:|
| 0 | 0 |
| 1 | 2 |
| 2 | 3 |
| 255 | 255 |

### 3.4 冲突处理与复核队列

1. 先按解码像素哈希、父样本和论文/页面来源合并重复项，保持现有 `test > val > train` 的划分优先级。
2. 相同图像在两个工作区出现时，不用来源前缀裁决：一致前景取并集；化学键优先；实线/虚线在同一像素冲突时写255并加入复核队列。
3. 实线工作区中含虚线的58条标注全部进入定向复核；虚线工作区99张真实图检查是否存在未区分的实线箭头。
4. 输出类型冲突像素数、复核样本数、各类像素数、跨划分重复和近重复报告。存在未复核类型冲突时拒绝构建正式数据集。

## 4. 同一母标签派生两个训练集

只保存一份图像和一份四分类母标签，生成两个训练视图：

- C 使用母标签原值：`0/1/2/3/255`。
- B 自动映射：`1、2 -> 1=arrow`，`3 -> 2=bond`，其余不变。

构建后逐图验证：

1. B/C 图像路径、父样本、划分和图像哈希完全相同；
2. B 的箭头掩膜必须逐像素等于 C 的实线与虚线掩膜并集；
3. B/C 的化学键与忽略区必须逐像素相同；
4. 所有增强视图只出现在训练集并跟随父样本划分。

数据集建议命名：

- 四分类母集：`UnifiedArrow-Type-Seg-v1`；
- 三分类派生视图：`UnifiedArrow-Type-Seg-v1/derived_three_class`。

本次生成的120张 `DocumentStyle-Candidates-v1` 不加入主对照。以后若加入，必须同时加入B和C并保持相同父样本抽样。

## 5. 严格锁定的训练条件

| 项目 | B与C共同配置 |
|---|---|
| 网络 | ResNet-101 U-Net++ |
| 初始化 | 相同 ImageNet 编码器初始化；解码器和分割头从相同规则随机初始化 |
| 输入 | 相同512×512训练块、相同白色填充、相同255忽略边界 |
| 抽样 | 每轮实线来源/虚线来源各50%，来源内均匀选父样本，再随机选一个视图 |
| 增强 | 相同几何与成像增强参数 |
| 优化器 | AdamW，初始学习率 `8e-5`，weight decay `1e-4` |
| 训练预算 | 固定80轮、相同每轮步数；主对照不因早停而改变总训练量 |
| 学习率 | 固定的同一调度表，不使用由各自验证分数触发的不同调度 |
| 随机性 | 首轮 seed 42；通过筛选后运行42、3407、2026三个种子 |
| 推理 | argmax，不为C单独调类别阈值 |

为避免“相同随机种子但抽样实际不同”，预先生成逐轮采样计划：样本ID、父样本、视图和增强种子。B/C读取同一计划，保证看到完全相同的输入块和顺序。

### 5.1 损失函数的控制

交叉熵保持相同的像素级语义权重：

- B：`[background=.20, arrow=1.0, bond=1.35]`
- C：`[background=.20, solid=1.0, dashed=1.0, bond=1.35]`

Dice按语义族保持总权重一致，避免C因为多出一个箭头类别而自动加大箭头损失：

- B：箭头0.5，化学键0.5；
- C：实线0.25，虚线0.25，化学键0.5。

主实验不同时引入Tversky、阈值调整或掩膜膨胀。若C证明类型分离有价值，再把损失优化作为后续消融。

## 6. 统一的选模和擦除规则

验证时先把C的类别1和2合并为 `arrow`，然后与B使用完全相同的指标与擦除代码。类别3作为化学键保护；化学键在箭头重叠处优先。

选模规则对B/C完全相同：

1. 化学键误删率不高于预先固定的0.3%；
2. 在满足保护条件的epoch中，最大化实线与虚线真实验证子集箭头IoU的等权平均；
3. 不使用四分类原始mIoU选C，因为它与B的类别数不同。

“实线/虚线子集”按四分类真实标签定义，而不是按数据来源前缀定义。混合图可同时进入两个类型统计；计算某一类型IoU时把另一箭头类型像素设为ignore，避免把正确检测到的另一类箭头计为假阳性。

## 7. 评价指标

### 7.1 主结果

- 合并后的全部箭头 IoU、Dice、precision、recall和残留率；
- 实线/弯曲箭头 IoU、recall和残留率；
- 虚线箭头 IoU、recall和残留率；
- 化学键误删率、背景误擦率、无箭头图误擦率。

### 7.2 四分类机制指标

- 实线被预测为虚线、虚线被预测为实线的交叉类型混淆；
- C在类型判断错误但箭头并集正确的像素比例；
- 接触/重叠区域中的合并箭头召回和化学键保护。

类型准确率只用于解释机制，不作为擦除任务的核心结论。四分类的价值必须体现为合并后箭头结果改善。

### 7.3 系统结果

- 相同硬件上的单图耗时、峰值显存和参数量；
- 相同OCSR后端上的结构有效率、Graph Exact Match或现有结构相似性指标；
- A必须以“双模型并行推理＋输出融合”名称报告，并与B/C使用同一原图和擦除规则。

## 8. 分阶段判定

### 8.1 单种子筛选

先运行seed 42。只有C同时满足以下条件才进入三种子正式训练：

- 虚线箭头IoU相对B提高至少2个百分点，或虚线残留率降低至少2个百分点；
- 实线箭头IoU相对B下降不超过1个百分点；
- 全部箭头IoU不低于B；
- 化学键误删率不超过0.3%，背景/无箭头误擦没有明显增加。

### 8.2 正式结论

通过筛选后，B/C均运行三个固定种子。在锁定测试集上按论文/专利页面做成组配对bootstrap，报告均值、标准差和差值置信区间。C只有在虚线改善可重复、实线与化学键保护保持、且OCSR结果不下降时，才作为统一模型候选。

现有测试集只有实线来源，20张真实虚线图已经参与历史选模。seed 42可以先完成机制筛选；用于论文或正式替换时，需要另锁定不参与选模的真实虚线测试集。

## 9. 执行顺序

1. 编写四分类母标签导出器和审计器；生成冲突复核队列。
2. 复核实线工作区58条含虚线标注及虚线工作区99张真实图的箭头类型。
3. 构建四分类母集并自动派生三分类视图；验证逐像素映射和划分一致性。
4. 生成固定采样/增强计划。
5. 分别对B/C做一次CPU或小图smoke test，确认损失、标签和四通道输出正确。
6. 用seed 42完成B/C固定预算训练与统一评估。
7. 达到筛选门槛后再补三个种子、独立虚线测试集和OCSR验证。
